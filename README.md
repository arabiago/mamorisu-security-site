# まもリスとカギまるのセキュリティ教室

中学生から大人まで、セキュリティの言葉や仕組みを「キャラクターの会話」と「さわって確かめられるコーナー」で学べる、1ページ3分の学習サイトです。サーバー処理のない静的なHTMLだけで動きます(GitHub Pages にそのまま置けます)。

## フォルダ構成

```
index.html            トップページ(サイト紹介+もくじ)
assets/style.css      共通デザイン(色・吹き出し・クイズ・計算機などのコーナー)
assets/site.js        もくじのデータ、左のもくじ、前後リンク、キャラクター画像
assets/quiz.js        確認クイズの共通処理
ch0/                  第0章 はじめに
ch1/                  第1章 本人確認(認証)
```

## ページを追加するとき

1. 既存のページ(例: `ch0/why-me.html`)をコピーして、本文を書きかえる
2. `assets/site.js` の `TOC` で、そのページの `href: null` を新しいファイルのパスに変える
   (まだ一覧にないページなら1行足す)

これだけで、左のもくじ・トップページの一覧・前後リンクに反映されます。

## クイズの書き方

各ページの下で `window.QUIZ` を書き、`assets/quiz.js` を読みこみます。

```html
<script>
window.QUIZ = {
  opts: ["秘密","正しさ","使えること"],   // 全問共通の選択肢(問題ごとに opts を書けば上書き)
  questions: [
    { q: "問題文", a: 0, why: "解説" }
  ],
  perfect: "全問正解のときの一言"
};
</script>
<script src="../assets/quiz.js"></script>
```

クイズを最後まで解くと、そのページに ✓ が付きます(閲覧者のブラウザにだけ保存され、どこにも送信されません)。

## LMS に載せるとき

LMS 側にもくじがある場合は、`assets/site.js` の先頭の `SHOW_SIDEBAR` を `false` にすると左のもくじを消せます。

## 公開(GitHub Pages)

リポジトリにこのフォルダの中身を置き、Settings → Pages で公開ブランチを選ぶだけです。
